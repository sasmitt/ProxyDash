ProxyCheck

Advanced proxy validation and network metadata analysis.

ProxyCheck is an advanced proxy testing and analysis platform designed for fast, reliable proxy validation and detailed network metadata analysis.

Built with a focus on speed, reliability, transparency, and developer-friendly tooling.

Developer

Diwas Khatri

What it checks

  • Multi-protocol support: HTTP, HTTPS, SOCKS4, SOCKS4A and SOCKS5 — with real protocol behavior probing, not just input prefixes
  • Latency analysis: connection, handshake, request and total response times
  • Exit IP detection and approximate geolocation (country, region, city, timezone)
  • ASN, ISP / network and organization information
  • Anonymity classification based on headers actually observed by the test endpoint
  • HTTPS / TLS tunnel support with full certificate validation
  • Authentication requirement detection with masked credentials

Honesty & accuracy

This is a multi-stage validation engine designed for reliable proxy verification — not a guarantee of 100% accuracy. Validation accuracy depends on the target, timeout, network conditions, proxy behavior, and geolocation provider. IP geolocation is approximate and may be inaccurate. Proxy status is a point-in-time measurement.

Responsible use

The application is intended for testing proxies supplied or authorized by the user. It uses controlled validation endpoints, strict SSRF protection, bounded concurrency and rate limits — it is not designed for bypassing authentication, attacking third-party systems or evading security controls.
